# Habit Tracker Pro

A polished habit tracker app built with Next.js, TypeScript, Tailwind, and a modern dashboard design.

## Features
- Add, edit, and delete habits
- Track completion for the last 30 days
- Streak summary and completion metrics
- Local JSON export / import
- Responsive, modern interface
- Privacy-first local storage

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
npm run build
npm run start
```

## Notes
This version is intentionally local-first and designed to be easy to extend. It can be upgraded to Supabase auth + database next.
